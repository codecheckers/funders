  <h2>Funders Study</h2>
  <p>
    The <em>Funders study</em> is the short name for our study:<br>
    <strong>“Using an Open Science Checklist in Grant Proposal Reviews to Predict Reproducibility of Funded Publications.”</strong>

    Protocol registration: https://doi.org/10.17605/OSF.IO/NS4V9
  </p>

  <h2>Data used for this study</h2>
  <ol>
     <li><code>db_master_grants_fullset.xlsx</code></li>
    <li><code>checklist.xlsx</code></li>
  </ol>

  <h2>Analysis code</h2>
  <ul>
    <li><code>analysis.R</code></li>
  </ul>

  <h2>What does the analysis code do? </h2>
  <ul>
    <li>Calculating prevalence of reproducibility.</li>
    <li>Calculating open science scores.</li>
    <li>Describing which grants that are resulting to reproducible publications</li>
    <li>Describing grant proposals characteristics with tables and graphs.</li>
    <li>Describing predicted vs actual reproducibility in 2x2 tables.</li>
    <li>Producing Accuracy Metrics (Se, Sp, PPV, NPV, overall accuracy).</li>
    <li>Producing AUC/ROC.</li>
  </ul>
 
  <h2>Software</h2>
     This analysis was done using R version 4.5.2 (https://www.r-project.org/).
